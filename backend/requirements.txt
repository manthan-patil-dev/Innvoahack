# Pinned against Python 3.11 (see .python-version). Every package below ships a
# prebuilt manylinux wheel for cp311, so a deploy installs binaries and never
# invokes a compiler.
#
# This matters: pydantic 2.10.4 pins pydantic-core 2.27.2, which publishes
# wheels for cp38-cp313 only. On a newer interpreter pip finds no wheel, falls
# back to building from source, and needs Rust + maturin — which is what fails
# on a hosted builder with a read-only Cargo directory.

uvicorn[standard]==0.34.0
pydantic==2.10.4
pydantic-settings==2.7.1
httpx>=0.27.0

# blocked outright, /api/health and /api/chat both still return 200.
#
